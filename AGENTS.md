# Agent instructions for qtile

See `docs/manual/contributing.rst` for the contribution guidelines.

## Reviewing changes

To review a change or pull request, follow
`.agents/skills/qtile-review/SKILL.md`. It checks the change against qtile's
project policies (no new threads, migrations for user-visible API changes,
backend parity, new dependencies, resource leaks in C code) and describes the
report format.
